Features:
 Create new tasks
 Update/edit tasks
  Delete tasks
  Organize tasks into:
   Todo
   In Progress
  Completed
 save data in mngo database
 
Technologies Used:
  Frontend: React.js
  Backend: Node.js & Express.js
  Database: MongoDB
  Other: REST APIs, Axios / Fetch\

  How to Run the Project
   1. Clone the repository
       git clone <your-repo-link>
      cd <project-folder>
  2. Setup Backend
     cd frontend
     npm install
    npm start
  3. Setup Frontend
    cd frontend
   npm install
   npm start
